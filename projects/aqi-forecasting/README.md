# 🌫️ AQI Forecasting with Machine Learning

A beginner-friendly machine learning project that demonstrates how environmental features can be used to estimate Air Quality Index (AQI).

## 🎯 Objective

Build a regression model that predicts AQI from features such as PM2.5, PM10, NO₂, CO, temperature, and humidity.

> **Note:** This portfolio project uses a reproducible synthetic dataset generated by the Python script. It is intended for learning and demonstration, not for real-world health or environmental decisions.

## 🧰 Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## 📁 Project Structure

```text
aqi-forecasting/
├── README.md
├── aqi_forecasting.py
└── requirements.txt
```

## 🚀 How to Run

```bash
pip install -r requirements.txt
python aqi_forecasting.py
```

The script generates sample environmental data, trains a Random Forest regression model, evaluates it with MAE and R², and saves an `aqi_actual_vs_predicted.png` chart.

## 🔬 Workflow

1. Generate reproducible environmental sample data.
2. Prepare features and target AQI.
3. Split the data into training and testing sets.
4. Train a Random Forest Regressor.
5. Evaluate predictions using MAE and R².
6. Visualize actual vs predicted AQI values.
